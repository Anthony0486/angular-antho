🔄 Two-Way Data Binding avec [(ngModel)]

Le Two-Way Binding associe simultanément le Property Binding [ ] et l'Event Binding ( ) pour synchroniser un champ de formulaire et une variable TypeScript en temps réel.

Moyen mnémotechnique : « Banana in a Box » [()]

N'oubliez pas d'importer FormsModule dans le tableau imports de votre composant Standalone !

✨ Exemple 1 : Champ texte dynamique

Saisissez du texte dans l'input. La propriété du composant est mise à jour instantanément sans écrire de méthode (input).

Bonjour {{ username || '(veuillez saisir un nom)' }} ! 

<input type="text" [(ngModel)]="username" />

⚡ Exemple 2 : Select et Checkbox

[(ngModel)] s'adapte automatiquement au type du champ HTML lié.

Recherche un Job

📊 Valeurs synchronisées dans le composant :

• Niveau : {{ studyLevel }}

• En recherche : {{ isSearchingJob ? 'Oui' : 'Non' }}

<select [(ngModel)]="studyLevel">...</select>
<input type="checkbox" [(ngModel)]="isSearchingJob" />

🔄 Action depuis la classe TypeScript

La liaison étant bidirectionnelle, modifier la valeur dans le code TypeScript met à jour immédiatement le HTML. 

// Dans le composant TypeScript :
resetForm() {
  this.username = '';
  this.studyLevel = 'Bac+3';
  this.isSearchingJob = false;
}
[(ngModel)] simplifie le code en combinant la lecture d'une propriété [ngModel] et l'écoute de l'événement de changement (ngModelChange).
